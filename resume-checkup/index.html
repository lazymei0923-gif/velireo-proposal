🩺 履歷健檢 Skill

用前 Google 招募官的六個判準，逐條幫你的履歷打分。裝一次，之後說一句「幫我看履歷」就會自己跑。

⬇️ 下載 Skill（zip）

裝進 Claude（全程在網頁上點，約 1 分鐘）

  1. 先到 設定 › Capabilities，把「Code execution and file creation」打開
    不開的話下一步會找不到上傳按鈕
  2. 打開 Customize › Skills
  3. 右上角 Add → Upload a skill，把剛下載的 zip 丟上去
    清單裡出現 resume-checkup 就裝好了

Pro 以上確定可以裝。免費版官方說法不一致，直接進去看有沒有 Add 按鈕就知道。

怎麼用

  1. 開一個新對話，把你的履歷丟進去（PDF、Word、純文字、截圖都行）
  2. 跟它說：
    幫我看履歷

有鎖定職缺的話，把職缺說明一起貼上，準確度差很多。
想直接改 104 就說「幫我改 104 履歷」——它會每一欄都先問過你才動。
